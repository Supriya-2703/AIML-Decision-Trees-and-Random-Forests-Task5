# Decision Trees and Random Forests using Heart Disease Dataset

## 📌 Objective

The objective of this project is to learn and implement tree-based machine learning models, including Decision Trees and Random Forests, for heart disease prediction. The project demonstrates how classification algorithms can be used to analyze patient health data and predict the presence of heart disease.

## 🛠 Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## 📂 Dataset

Used the Heart Disease Dataset for classification analysis and prediction.

### Dataset Information

* 1025 records
* 13 input features
* 1 target variable (`target`)

  * 0 = No Heart Disease
  * 1 = Heart Disease

## 🔍 Tasks Performed

* Imported and explored the dataset.
* Performed data preprocessing and analysis.
* Split the dataset into training and testing sets.
* Trained a Decision Tree Classifier.
* Visualized the Decision Tree structure.
* Analyzed overfitting by varying tree depth.
* Controlled model complexity using `max_depth`.
* Trained a Random Forest Classifier.
* Compared the performance of Decision Tree and Random Forest models.
* Evaluated feature importance scores.
* Applied Cross-Validation for model evaluation.
* Generated classification reports and confusion matrices.

## 📊 Output

* Trained Decision Tree model.
* Decision Tree visualization.
* Overfitting analysis graph.
* Trained Random Forest model.
* Model accuracy comparison.
* Feature Importance visualization.
* Cross-Validation scores.
* Classification Report.

## 🚀 Conclusion

This project provided hands-on experience with Decision Trees and Random Forests for classification tasks. The Decision Tree model offered easy interpretability, while the Random Forest model improved prediction accuracy and reduced overfitting through ensemble learning. Cross-validation further confirmed the reliability and robustness of the models for heart disease prediction.
